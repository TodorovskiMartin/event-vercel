# Event Day Runbook

## Several Days Before

- Production Vercel deployment complete.
- Production Supabase project configured.
- Organizer account created.
- Album event entered with exactly 10 songs.
- QR generated and printed.
- Load test passed against a staging/test event.
- Venue internet tested.

## Before Guests Arrive

- Open organizer dashboard.
- Open projector page on main laptop.
- Have backup laptop logged in.
- Prepare hotspot or second internet option.
- Test QR from several phones.
- Confirm event is `waiting` and test votes are reset.

## During Event

- Display QR.
- Watch confirmed vote count.
- Open voting only at the announcement.
- Leave enough time for slow networks.
- Close voting.
- Reveal results from the projector page.

## Emergency

- Use the fallback table on the projector page.
- Export/view totals from the dashboard.
- Switch organizer laptop connection if venue internet degrades.
